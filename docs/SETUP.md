# Подключение EL_Store

1. Разверните этот репозиторий как отдельный Cloudflare Worker через `npm run deploy` или интеграцию Workers & Pages. Конфигурация `wrangler.jsonc` создаёт отдельное SQL Durable Object `NewsletterStore`; используйте отдельное имя `el-store` и не меняйте привязку CR_Reserve.
2. В настройках Worker задайте **Secrets** `BOT_TOKEN` от @E_NewSletters_Bot, `ADMIN_IDS` (числовой Telegram ID владельца; несколько ID через запятую) и `ORDER_CHAT_ID` (ID рабочего канала `-100…` либо `@username` публичного канала). Токен храните только в Cloudflare, не в GitHub и не в коде. `WEBHOOK_SECRET` необязателен: кнопка «Подключить бота» безопасно создаёт собственный секрет в хранилище.
3. Добавьте @E_NewSletters_Bot администратором канала с разрешением публикации. Для приватного канала после установки `BOT_TOKEN` и `ADMIN_IDS` откройте бота и перешлите ему сообщение из канала с сохранением источника. Он сообщит ID канала; внесите его в `ORDER_CHAT_ID` и повторно разверните Worker.
4. В @BotFather создайте Mini App для @E_NewSletters_Bot, укажите **https://el-store.elereas.workers.dev**. Если BotFather выдаст короткую ссылку вида `https://t.me/EL_Store_Bot/<app>`, используйте её для входа. Меню бота также настраивается внутри приложения.
5. Откройте Mini App своим Telegram-аккаунтом → **Управление → Подключить бота**. Это настроит webhook, команды и кнопку «Товары». Если нужно, `npm run dev` предоставляет локальную проверку, но вход Telegram и доставка в канал требуют публичный HTTPS.
6. В «Управление» создайте бренд через «Добавить бренд» или выберите существующий → «Загрузить/Обновить Excel» → проверьте товары, цены и остатки → назначьте каждому товару одну из категорий бренда → сохраните каталог. Поддерживается отчёт остатков: Код, Наименование, Изображение, Доступно, Цена продажи. Excel загружается в браузере владельца; перед сохранением можно заполнить цены, а фото сжимаются.

Пока `BOT_TOKEN` не задан, приложение показывает только демонстрационный предпросмотр. При отсутствующем `ORDER_CHAT_ID` оформление заказов заблокировано, чтобы заказ не потерялся без канала. Изменение количества в опубликованном поступлении не может сделать остаток ниже уже оформленных заказов. Для EL Store колонка остатка в Excel считается **актуальным текущим остатком**. При повторной загрузке цена и остаток обновляются по артикулу; отсутствующие позиции скрываются.


## Колонки отчёта остатков

| В Excel | В приложении |
|---|---|
| Код | Артикул |
| Наименование | Наименование |
| Изображение | Изображение |
| Доступно | Кол-во |
| Цена продажи | Цена |

«Код» имеет приоритет над «Артикул», «Доступно» — над «Остаток» и «Кол-во», «Цена продажи» — над другими ценами. «Резерв» и «Сумма продажи» не используются для расчёта количества и цены. Пустая цена продажи требует заполнения перед сохранением, даже если другая цена указана. Порядок колонок и регистр названий не важны. Встроенные фото XLS/XLSX сопоставляются с товарами по строкам и сжимаются при импорте.

## Фиксированные категории товаров

После загрузки Excel каждому товару нужно назначить одну из категорий бренда:

- Apple: **Оригинал**, **Копия**.
- Remax: **GL-27**, **GL-27 Privacy**, **ES-01**.

Категории заранее заданы в приложении: создавать, переименовывать или удалять их нельзя. Для существующих артикулов назначение сохраняется при следующем обновлении Excel. Новым артикулам категорию нужно выбрать вручную перед сохранением.

Товары, которых нет в новом Excel, автоматически скрываются. Если такой артикул позже снова появится в файле, прежняя категория и сохранённое изображение восстанавливаются, если они были известны приложению. Товары с нулевым остатком покупателю не показываются.
