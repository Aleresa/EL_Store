# EL_Store

Telegram Mini App **EL Store** — магазин товаров с каталогами **Apple и Remax**.

## Как работает

Категории: Apple — Оригинал / Копия; Remax — GL-27 / GL-27 Privacy / ES-01.

- Главная вкладка **Товары** показывает два бренда в две колонки: Apple и Remax.
- Поиск вверху главной ищет товары обоих брендов по названию, модели, категории и артикулу.
- Внутри бренда сначала открываются фиксированные категории, затем компактный список товаров и поиск.
- **Общая корзина Apple + Remax**: товары обоих брендов оформляются одним заказом. Остатки проверяются и списываются в одной транзакции.
- Корзина и комментарий сохраняются на устройстве отдельно для каждого Telegram-аккаунта. При открытии корзины и перед оформлением проверяются текущие цены и остатки; изменения показываются покупателю до подтверждения.
- Незавершённая отправка сохраняет ключ запроса: после обрыва связи кнопку «Проверить отправку» можно нажать снова без создания второго заказа.
- Фото товара открывается крупно по нажатию, закрывается крестиком или Escape.
- В истории есть **Повторить заказ**: доступные позиции добавляются в текущую корзину по актуальным ценам. Недоступные товары и ограничение количества показываются отдельно; заказ автоматически не отправляется.
- Списки и общий поиск сортируются по цене, названию и новизне. Фильтр iPhone строится из моделей, явно указанных в названиях, включая несколько моделей через `/`; совместимость не предполагается. Если модели в названиях не указаны, селектор не показывается.
- Новизна — дата первого добавления артикула после обновления приложения; обычная перезагрузка Excel её не меняет. Для ранее загруженных товаров без даты сохраняется порядок каталога.
- **Мои Заказы** показывает историю и позволяет редактировать/отменять заказ до подтверждения.
- **Управление** доступно администратору: обновление каталогов из XLS/XLSX, распределение по фиксированным категориям и все заказы.
- Excel обновляет товары **по артикулу**: актуальные цена и остаток берутся из нового файла, а категория назначается из фиксированного списка бренда.
- Если артикул исчез из нового Excel или остаток равен 0, товар автоматически скрывается у покупателей.
- Оформленные ранее заказы сохраняются при обновлении каталога.
