# EL_Store

Telegram Mini App **EL Store** — магазин с управляемыми брендами и каталогами. Apple и Remax настроены при первом запуске.

## Как работает

Категории: Apple — Оригинал / Копия; Remax — GL-27 / GL-27 Privacy / ES-01.

- Главная вкладка **Товары** показывает опубликованные бренды в две колонки.
- Поиск вверху главной ищет товары всех опубликованных брендов по названию, модели, категории и артикулу.
- Внутри бренда сначала открываются категории, созданные администратором, затем компактный список товаров и поиск.
- **Общая корзина всех брендов**: товары всех опубликованных брендов оформляются одним заказом. Остатки проверяются и списываются в одной транзакции.
- Корзина и комментарий сохраняются на устройстве отдельно для каждого Telegram-аккаунта. При открытии корзины и перед оформлением проверяются текущие цены и остатки; изменения показываются покупателю до подтверждения.
- Незавершённая отправка сохраняет ключ запроса: после обрыва связи кнопку «Проверить отправку» можно нажать снова без создания второго заказа.
- Фото товара открывается крупно по нажатию, закрывается крестиком или Escape.
- В истории есть **Повторить заказ**: доступные позиции добавляются в текущую корзину по актуальным ценам. Недоступные товары и ограничение количества показываются отдельно; заказ автоматически не отправляется.
- Списки и общий поиск сортируются по цене, названию и новизне. Фильтр iPhone строится из моделей, явно указанных в названиях, включая несколько моделей через `/`; совместимость не предполагается. Если модели в названиях не указаны, селектор не показывается.
- Новизна — дата первого добавления артикула после обновления приложения; обычная перезагрузка Excel её не меняет. Для ранее загруженных товаров без даты сохраняется порядок каталога.
- **Мои Заказы** показывает историю и позволяет редактировать/отменять заказ до подтверждения.
- **Управление** доступно администратору: обновление каталогов из XLS/XLSX, распределение по категориям бренда и все заказы.
- Excel обновляет товары **по артикулу**: актуальные цена и остаток берутся из нового файла, а категория назначается из списка категорий бренда.
- Если артикул исчез из нового Excel или остаток равен 0, товар автоматически скрывается у покупателей.
- Оформленные ранее заказы сохраняются при обновлении каталога.

## Уведомления в канал

В «Управление → Уведомления в канал» показаны настроенный канал, права бота, очередь и последняя ошибка Telegram. Кнопка «Отправить ожидающие» повторяет доставку сохранённых заказов; уже доставленные сообщения обновляются. Для канала у бота должно быть право «Публикация сообщений». `ORDER_CHAT_ID` — один числовой ID или @имя, без пригласительной ссылки.

При открытии приложения кнопка меню Telegram обновляется на «Сделать Заказ», включая персональное меню чата. Эта операция не меняет webhook.

## Управление брендами

«Управление → Добавить бренд»: название, категории по одной на строку и необязательная обложка JPG/PNG/WebP. Обложка сжимается в браузере. Новый бренд сначала скрыт; после создания откроется загрузка XLS/XLSX. Распределите товары по категориям и включите «Показывать бренд покупателям после сохранения».

Кнопка «Настройки» позволяет изменить название, обложку, категории и видимость. Скрытие убирает бренд из поиска и новых заказов, сохраняя товары, остатки и историю. Для удаления занятой категории сначала добавьте новую и перенесите товары через редактор каталога. Старые заказы сохраняют название бренда на момент оформления.

Бренды хранятся в таблице `brands`. Начальные Apple/Remax добавляются только при отсутствии записи; пользовательские настройки не перезаписываются при развёртывании. Ранее удалённые каталоги автоматически не восстанавливаются.

В настройках бренда раздел «Обложки категорий» позволяет загрузить, заменить или убрать отдельное изображение для каждой категории. JPG/PNG/WebP до 15 МБ сжимаются в браузере; обложки сохраняются вместе с брендом и не сбрасываются при обновлении Excel. Загруженная обложка отображается на карточке категории в Web App и Telegram Mini App.
