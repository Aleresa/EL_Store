# EL_Store

Telegram Mini App **EL Store** для товаров в наличии. Основа функциональности перенесена из CR_Newsletters, но приложение использует отдельный Cloudflare Worker, Durable Object и Telegram-настройки.

## Что умеет

- вкладка **Поступление** с остатками, ценами, поиском и группами товаров;
- корзина и оформление заказа с выбором менеджера;
- **Мои заказы**: просмотр, редактирование и отмена до подтверждения;
- **Управление** для администратора: импорт XLS/XLSX, ручные группы, публикация/закрытие поступлений, менеджеры, экспорт заказов;
- отправка и обновление заказа в рабочем Telegram-канале;
- отдельное хранилище EL Store без пересечения с CR_Newsletters.
