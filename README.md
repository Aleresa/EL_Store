# EL_Store

Telegram Mini App **EL Store** — магазин товаров с каталогами **Apple, Remax и Gurdini**.

## Как работает

- Главная вкладка **Товары** показывает три бренда: Apple, Remax, Gurdini.
- Внутри бренда — компактный список товаров, поиск и ручные группы/фильтры.
- Покупатель выбирает количество, менеджера и оформляет заказ.
- **Мои Заказы** показывает историю и позволяет редактировать/отменять заказ до подтверждения.
- **Управление** доступно администратору: обновление каталогов из XLS/XLSX, группы товаров, менеджеры и все заказы.
- Excel обновляет товары **по артикулу**: актуальные цена и остаток берутся из нового файла.
- Если артикул исчез из нового Excel или остаток равен 0, товар автоматически скрывается у покупателей.
- Оформленные ранее заказы сохраняются при обновлении каталога.
