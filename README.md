# EL_Store

Telegram Mini App **EL Store** — магазин товаров с каталогами **Apple и Remax**.

## Как работает

Категории: Apple — Оригинал / Копия; Remax — GL-27 / GL-27 Privacy / ES-01.

- Главная вкладка **Товары** показывает два бренда в две колонки: Apple и Remax.
- Поиск вверху главной ищет товары обоих брендов по названию, модели, категории и артикулу.
- Внутри бренда сначала открываются фиксированные категории, затем компактный список товаров и поиск.
- Покупатель выбирает количество и сразу оформляет заказ.
- **Мои Заказы** показывает историю и позволяет редактировать/отменять заказ до подтверждения.
- **Управление** доступно администратору: обновление каталогов из XLS/XLSX, распределение по фиксированным категориям и все заказы.
- Excel обновляет товары **по артикулу**: актуальные цена и остаток берутся из нового файла, а категория назначается из фиксированного списка бренда.
- Если артикул исчез из нового Excel или остаток равен 0, товар автоматически скрывается у покупателей.
- Оформленные ранее заказы сохраняются при обновлении каталога.
